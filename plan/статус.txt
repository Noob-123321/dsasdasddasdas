## Оставшиеся production-dependent items

- PostgreSQL/Redis Docker stack не запускался на этой Windows-машине: Docker CLI
  не установлен. Compose-файлы и миграции присутствуют, но полный PG integration
  прогон нужно выполнить в окружении с Docker.
- Initial migration использует `Base.metadata.create_all`; schema history нужно
  пересмотреть перед production.
- PostgreSQL FK migration 0003 проверен только на fresh SQLite; реальный PG
  прогон обязателен перед production.
- Webhook SSRF hardening (DNS/redirect/egress), API scope/quota enforcement,
  delivery history и полноценная stream-session model остаются backlog.
- Реальный `TWITCH_SOURCE=gql` проверен на публичных live/offline каналах;
  адаптер может измениться при отзыве/изменении Twitch CommunityTab.
- Telegram delivery и production webhook retries подключены как backend
  contracts; локальный smoke test проверяет in-app alert path и webhook
  registration/security, но не реальный внешний endpoint.
- Для production нужно задать `COOKIE_SECURE=1`, HTTPS reverse proxy и
  secret-manager values.
